# Population-structure-of-Ommatogammarus-flavus-and-O.-albinus
This github repository was created for an article about the population structure of two eurybatic species of Baikal amphipods of the genus *Ommatogammarus* (to be submitted).


Because there is a lot of supporting data, here is a table that hopefully helps to find the necessary information:


|Manuscript Section|Main Figure|Supporting Information|
|--|--|--|
|Introduction|Fig. 1 (animal habitus)|Figure S1 (coxae photos); File S1 (descriptions)|
|Materials & Methods | Fig. 2 (map of sampling spots) | Table S1 (coordinates and sample sizes)
|Materials & Methods | -- | Files S2 and S3 (partial mtDNA sequences of *O. flavus* and *O. albinus* with annealed primers); Tables S2 (primer sequences) and S3 (primer combinations)
|Results | Fig. 3 (COI network for all spots) | File S4 (multiple sequence alignment)
|Results | Fig. 4 (COI network for depths in Bolshie Koty) | File S4 (multiple sequence alignment)

|Results | Fig. 7 (eye color and shape) | Figure S4 (all photographs)
